## FastAPI Project
This is a basic FastAPI application managed with the `uv` package manager.

## How to launch the project
1. Make sure you have `uv` installed on your system.
2. Open your terminal in the root directory of the project.
3. Install the dependencies (if you haven't already):
    ```bash
    uv sync
4. Start the project 
    ```bash
    uv run fastapi dev main.py
